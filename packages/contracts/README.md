# @rusuh/contracts

Shared contracts for the rusuh-core Node modules: API error codes (RFC 9457
Problem, repo contract `api/openapi.yaml`), Joi schemas, and decided constants
(TTLs, quotas, fees, queue names, Valkey namespaces).

Source of truth for the values: the decisions file + ADR-0021–0026 (5–6 Nov 2026).
